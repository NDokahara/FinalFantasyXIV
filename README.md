# NDokahara's Dalamud Plugins

This repository is the plugin list. It holds one file — `repo.json` — which tells Dalamud
what plugins exist and where to download them. The plugins themselves live in their own
repositories, one each.

## Adding the repository

In game, once:

1. `/xlsettings` → **Experimental**
2. Under **Custom Plugin Repositories**, paste:

   ```
   https://raw.githubusercontent.com/NDokahara/FinalFantasyXIV/main/repo.json
   ```

3. Tick the checkbox next to it, then **Save and Close**
4. `/xlplugins` → find the plugin → Install
